<h3> ClearFund is for personal use only and for further study on iOS and SWIFT. </h3>

This app allows you to log in with a user account and save your savings and expenses, which can be filtered weekly, monthly, and annually.
It allows you to categorize expenses such as groceries, rent (including bills), and entertainment.
- `AppStrings.text` builds the localized key from the raw value at runtime, so Xcode won't auto-extract keys into a String Catalog; add them manually if you introduce one.
